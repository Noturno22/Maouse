> Regra-mestra mantida: **a IA gera o CGI; os momentos de prova (`[CORTE REAL]`) são gravação real**

## 1. Porquê Hyper Motion para o Mãouse

| Vantagem | Detalhe |
|---|---|
| **Sem pessoas** | Não depende de atores, release, nem filmagem de terceiros. |
| **Sem locução** | Só música + SFX — atravessa idiomas; PT-BR/EN só no texto de ecrã. |
| **Produto como herói** | "O rato é software" tem visual: cursor de luz no ar, webcam a brilhar. |
| **Rápido** | 15 s por geração (Seedance 2.0) → montagem de 2–3 clips no editor = spot completo. |

> **Alternativa do Higgsfield para software:** se o plano incluir **Motion Design** (entrada = logo
> ou website, não foto de produto), é a opção ideal para *motion-graphics* de marca. Usar para
> clips abstratos; para Hyper Motion usa-se a ref do produto (logo/screenshot do ecrã + foto da
> webcam/cursor). Verificar o modo no painel (template "Motion" → Hypermotion / 2D Product Motion /
> Motion Design).

## 4. Workflow no Higgsfield (passo a passo)

| Passo | Ação |
|---|---|
| 1 | Configurar **Brand Kit** (logo/cores de `maouse.app`) → consistência automática. |
| 2 | Criar perfil do produto (logo + screenshot do ecrã + foto da webcam; até 5 imagens). |
| 3 | Escolher o template **Motion → Hyper Motion** (15 s/geração). |
| 4 | Gerar as cenas CGI dos slots; usar **Grid Mode** para até 16 variações e escolher a melhor. |
| 5 | Exportar cada clip; montar no editor (Premiere/CapCut): intercalar com os `[CORTE REAL]`. |
| 6 | Adicionar texto de ecrã PT-BR + EN, música e SFX. Sem locução (formato é sem VO). |
| 7 | Exportar 16:9 + 9:16 (vertical); watermark discreto na versão Free. |

> **Resultado esperado:** 1–3 clips CGI gerados + 2–4 cortes reais = spot Hyper Motion completo,
> com o produto real provado no meio.
